# Changelog

## v0.1 (public playtest)

First public build.

- All game text translated: story (43 scripts), battle quotes, names, descriptions, help,
  menus and system messages, terrain names.
- Proportional English font (Fira Sans) in dialogue, menus, the backlog and number displays.
- Picture text in English: title logo, warning screen, menu titles, map and battle labels,
  command badges, Special Disk menus, Shuffle Battler card art and labels.
- Terrain ranks shown as icons; spirit legend as two-letter tiles; English name-entry grid.
- No editing pass yet: see the README.
